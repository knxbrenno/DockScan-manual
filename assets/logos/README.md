Logos das distribuições, linguagens, serviços e formatos do capítulo "O que o DockScan reconhece", obtidas do projeto Simple Icons (https://github.com/simple-icons/simple-icons), versão 16.30.0, sob CC0-1.0. As marcas pertencem aos respectivos titulares. As cores foram ajustadas para contraste de 3:1 nos temas claro e escuro do manual. Os ícones genéricos (terminal, globo, cadeado e os outros) foram desenhados para o manual e ficam com os protocolos e os itens sem logo própria. Nenhum recurso remoto é carregado pela página.
